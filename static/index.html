CARA KERJA

Dari ide ke produksi

AI Video Studio membantu menyiapkan rencana, aset, dan prompt. Video dibuat di platform tujuan pilihan Anda.

  1. Mulai dari cerita sederhana; gunakan kerangka manual, Ollama lokal, atau Gemini API opsional.
  2. Tinjau cerita dan sunting setiap adegan.
  3. Tambahkan gambar referensi dan tautkan ke adegan.
  4. Salin prompt, produksi manual di platform, lalu catat progres klip.

Gemini hanya mengirim ringkasan ide setelah Anda memilih provider dan meminta draft. API key berada di environment server. Draft tidak diterapkan sebelum Anda meninjau dan mengonfirmasi. Proyek tersimpan di komputer ini.
